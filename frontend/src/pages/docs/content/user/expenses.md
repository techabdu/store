# Expenses

Track shop expenses directly from the dashboard.

## Recording an Expense

1.  Navigate to the **Expenses** page.
2.  Click **Add Expense** button.
3.  Fill in the details:
    *   **Category**: Choose from predefined categories (e.g., Maintenance, Supplies, Utility).
    *   **Amount**: Enter the cost.
    *   **Description**: Brief note about the expense (e.g., "Printer paper").
    *   **Date**: Defaults to today.
4.  Click **Save**.

## Viewing Expenses

You can view a list of expenses you have recorded. Admins can see expenses from all staff members.
