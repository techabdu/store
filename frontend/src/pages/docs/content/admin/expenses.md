# Expense Management

Admins have oversight of all expenses recorded in the system.

## Viewing All Expenses

Unlike the standard user view, the Admin **Expenses** page shows records from **all staff members**.

1.  Use the date picker to view expenses for a specific period.
2.  Filter by Category to see where money is being spent (e.g., how much was spent on "Utilities" this month).

## Auditing Expenses

*   Check the "Recorded By" field to see which staff member entered the expense.
*   **Delete**: Admins can remove incorrect expense entries using the delete icon.
