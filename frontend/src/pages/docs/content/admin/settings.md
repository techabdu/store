# Shop Settings

Configure the core behavior of your PRHub instance.

## General Settings

*   **Shop Name**: Appears on receipts and the dashboard.
*   **Address & Contact**: Printed on receipts.
*   **Currency**: Set the default currency symbol (e.g., $, ₦, £).

## Preferences

*   **Receipt Footer**: Custom message to print at the bottom of receipts (e.g., "Thank you for your patronage! No refunds after 7 days.").
*   **Tax Rate**: Set a default tax percentage if applicable.

> **Note**: Changes to settings apply immediately across the system.
